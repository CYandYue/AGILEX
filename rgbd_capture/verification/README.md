# 验证记录

- 14 项离线测试通过：延迟位姿关联与解析轨迹对照、字节序/行填充、像素模型、里程计缺口、时钟倒退、无效深度、RGB-D 错时、畸变导出、浮点深度和 NaN、外参变化、损坏/不完整 bag 拒绝、原始消息保存，以及原始 bag 合并的 latched TF 保留、缺失原始数据拒绝和防覆盖。
- `synthetic_live.json` 保留首次实现的合成在线测试结果（35 帧、约 6 Hz）。
- `synthetic_raw_live.json` 为本次修复后的合成在线测试：640×480、30 Hz 图像输入，另有两路大消息及三路 IMU 负载；独立 C++ 原始录制、Ctrl-C 收尾、合并及校验通过。35 帧、5.99 Hz，队列峰值 31 条。合成雷达消息为标准 String，测试不依赖 Livox 包，消息率不等同于实机。
- `hardware_raw_live.json` 为本次静态实机测试：双 MID360、外置 HI226、D435 联合启动，无 RViz、无底盘控制；相机 640×480、6 FPS，彩色 auto_exposure_priority=false；录制带 `--raw-sensors --duration 20`。最终生成单个约 134 MiB bag，51 个完整帧组，图像时间跨度内平均 2.85 Hz，队列峰值 43 条 / 3.60 MiB，无溢出。两路雷达各 187 条、三路 IMU 均有数据；合并后的原始话题消息数核对和相机位姿复算通过。
- 此前相机 15 FPS 的静态联合录制约 1.3–1.6 Hz；6 FPS 是根据本机测试选择的配置，不能据此保证所有环境中的最低帧率。用户当前要求为完整帧组超过 2 Hz。
- shell 入口语法、Git diff 空白检查通过。合并及校验所需时间不含在报告的 elapsed_wall_s 中；本机收尾可需要几十秒，必须等待 Validated bag。

上述实机测试为静态短测，未验证移动中的时间标定或融合精度。原始安装外参、硬件同步及 LIO 延迟仍以实际系统状况为准；有效帧严格使用前后 LIO 位姿插值，没有用外推或重复图像补帧。运行方法见上一级 README。
